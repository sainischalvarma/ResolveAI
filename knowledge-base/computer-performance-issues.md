# Computer slow, frozen, or not starting

**Category:** General computer problems / System  
**Target:** Windows and macOS workstations

## Problem
The computer is very slow, frozen, or will not start properly.

## Troubleshooting Steps
1. **Restart computer:** Save open work and perform a full reboot.
   - *Expected:* Performance improves after a clean reboot.
2. **Close heavy applications:** Open Task Manager / Activity Monitor and terminate non-responsive apps.
   - *Expected:* CPU and memory resources free up.
3. **Pending OS updates:** Check for and install pending operating system updates, then restart.
   - *Expected:* System stability and patches applied.
4. **Free disk space:** Check storage drive and remove temporary files if space is under 10%.
   - *Expected:* Sufficient swap space available.
5. **Hard power reset:** If device will not power on, verify power cable, hold power button 10s, then turn on.
   - *Expected:* Device powers on and boots into OS.

## Expected Result
The computer runs normally and is responsive.

## Escalation Conditions
Device will not boot, blue-screen (BSOD) loops, physical hardware failure, or business-critical machine down.
