# Wi-Fi not connecting

**Category:** Wi-Fi / Network  
**Target:** Devices unable to connect to wireless network

## Problem
Wi-Fi is not working or the device cannot connect to a wireless network (e.g. 'Can't connect to this network').

## Troubleshooting Steps
1. **Confirm Wi-Fi is turned on:** Check the Wi-Fi toggle / ensure airplane mode is off.
   - *Expected:* The Wi-Fi list shows available networks and the organization network is visible.
2. **Forget network and reconnect:** Re-enter the network password.
   - *Expected:* The device reconnects successfully.
3. **Restart Wi-Fi adapter:** Or toggle airplane mode on then off.
   - *Expected:* The adapter re-scans and connects.
4. **Restart device:**
   - *Expected:* A clean network stack reconnects automatically.
5. **Move closer to access point:** Rule out weak signal strength.
   - *Expected:* Stronger signal and a stable connection.

## Expected Result
The device connects to the Wi-Fi network and can browse the internet.

## Escalation Conditions
All steps attempted and still no connection, OR multiple users/devices cannot connect, OR the access point appears down.
